Branding & Style Customization

The template is designed with maximum flexibility in mind. You can update the brand styling and look-and-feel of the site simply by changing a few CSS variables.

1. Modifying Brand Colors

Open Template/css/variables.css in your code editor. Locate the color tokens block inside the :root selector. Update the color hex codes and the corresponding RGB values:

/* Color variables example */
:root {
  --primary-rgb: 15, 23, 42;      /* Slate 900 */
  --primary: rgb(var(--primary-rgb));
  --accent-rgb: 197, 168, 128;   /* Warm Gold / Champagne (#c5a880) */
  --accent: rgb(var(--accent-rgb));
  --accent-hover: #B49469;       /* Hover Gold */
  --accent-dark: #9F825C;        /* Secondary Dark Gold */
}

Note: The RGB variables (e.g. --primary-rgb) are required for background transparency overlays (such as hero filters and testimonial card backdrops) to dynamically adjust to your colors.

2. Modifying Fonts

The template utilizes Playfair Display for headings and Plus Jakarta Sans for body copy. To replace them:

  • Change the import URL at the top of Template/css/base.css.
  • Update the --font-serif and --font-sans variables in Template/css/variables.css.

Properties & Agents Data

You do not need to edit complex HTML blocks to add, edit, or remove property listings or advisor profiles. All website data is loaded from Template/js/data.js.

1. Properties Array Format

Each property in the PROPERTIES_DATA array has the following structure:

{
  id: "prop-01",
  title: "The Obsidian Modern Villa",
  type: "villa", // Match filter type: villa, penthouse, mansion, apartment
  location: "Beverly Hills, CA",
  price: 14500000,
  beds: 6,
  baths: 8,
  area: 9200,
  image: "assets/images/prop_villa.png", // Path to local asset
  featured: true, // If true, displays in the Featured section
  tag: "Exclusive", // Badge text
  description: "An architectural tour de force..."
}

2. Adding Your Own Images

Save your property and agent images inside Template/assets/images/ (optimized WebP or PNG format is highly recommended for speed), and update the image or photo paths in Template/js/data.js accordingly.

SEO & Accessibility Best Practices

Veridian Estates complies with modern SEO guidelines and meets **WCAG AA accessibility guidelines** out of the box.

1. Structured Data (JSON-LD)

The template includes a local schema markup tag in Template/index.html. Update it with your agency's phone number, address, and email coordinates so Google can index your business details:

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "RealEstateAgent",
  "name": "Your Agency Name",
  "image": "https://yourdomain.com/assets/images/hero_bg.png",
  "telephone": "+18005559800",
  ...
}
</script>

2. Accessibility Focus Ring Styles

Keyboard navigators will see a visible, outline ring when highlighting interactive links and buttons. Focus states are handled in Template/css/base.css under the :focus-visible rules.

Frequently Asked Questions

Q: Can I use this template on multiple domains?

A: A standard license allows deployment on **one single domain**. If you are building multiple client projects, you must purchase a separate license code for each site.

Q: How do I hook up the form submissions to a real server?

A: The form submits asynchronously to a mock timeout handler in Template/js/app.js. To send inquiries to your email box, change the form submission action or integrate a cloud mailing tool like Web3Forms, Netlify Forms, Formspree, or configure a backend script like PHP mailer:

// Edit the initContactForms submit logic in js/app.js:
// fetch("your-server-endpoint", { method: "POST", body: new FormData(form) })
Important: Always escape user input variables if you are displaying submitted messages back to the screen to prevent script injection (XSS) risks.
