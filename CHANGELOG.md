# Changelog — Veridian Estates Website Template

All notable changes to this project will be documented in this file.

---

## [1.0.0] - 2026-07-19
### Added
- **Initial Release**: Launch of Veridian Estates luxury real estate template.
- **Dynamic Property Filters**: Built-in real-time catalog search, type filtering, bedroom range matching, and max price limits with visual shimmer transitions.
- **Interactive Modals**: Focus-trapped accessible dialog modal for booking consultation inquiries.
- **Offline Assets Pack**: Created local optimized WebP/PNG property images, agent profiles, favicons, and site webmanifest assets.
- **Accessibility Integration**: Added keyboard visible outlines (`:focus-visible`), skip-to-content anchors, ARIA role descriptors, and proper semantic HTML labels.
- **SEO Elements**: Implemented Structured JSON-LD schema, Twitter Cards, Open Graph tags, canonical URLs, and robots/sitemap placeholders.
- **Marketplace Package Structure**: Grouped template resources, offline documentation sites, and attributions.
- **Documentation Guide**: Created responsive detailed offline setup index documentation page.
